# Wind Forecast Desk

> 🚧 Work in progress

A web app for a UK utility's day-ahead trading desk. It shows the latest national wind generation forecast available at the day-ahead auction gate closure and measures how accurate that forecast turned out to be. Scope: purchase decisions made in January 2026.

**Data:** Elexon BMRS: `FUELHH` (actual wind generation) and `WINDFOR` (wind forecasts).
**Stack:** Python (FastAPI) backend · React (TypeScript) frontend · Docker.

Setup instructions, architecture and findings will follow as the project comes together.
